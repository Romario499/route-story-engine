# Route Story Engine

GPS-трек или коллекция меток → анимированная видеоистория. Vite + TypeScript strict, MapLibre 4.7.1, WebCodecs; без аккаунтов, ключей и бэкенда. Вариант сдачи — **воспроизводимый локальный запуск**. Публичного адреса в материалах сдачи нет.

## Демо за 2 минуты

1. Запустите `npm ci`, затем `npm run dev`; откройте локальный адрес Vite в десктопном Edge или Chrome. В PowerShell используйте `npm.cmd`.
2. Откройте пример-реконструкцию @wahrier или выберите свой GPX/KML/KMZ/GeoJSON/CSV. Студия автоматически строит превью.
3. Основные стили — **«Экспедиция»** (спутник, рельеф, янтарная линия, Manrope) и **«Атлас»** (светлая карта с отмывкой, PT Serif); **«Неон»** — тёмная карта и JetBrains Mono. При желании выберите формат 9:16/16:9 и длительность 15/30/45/60 с; расширенные настройки не обязательны.
4. Нажмите Play, затем **«Экспортировать ролик»**. Полный файл скачивается автоматически; его можно проиграть и скачать повторно. При неполных тайлах появляется отдельное предупреждение, автоматического скачивания нет.

Не сворачивайте вкладку на время экспорта. Две минуты — сценарий знакомства, не обещание времени экспорта на любом оборудовании.

## Локальный запуск

Нужен Node.js ≥ 22.18 для скриптов с прямым импортом TypeScript (проверено на Node 24.15.0).

```bash
npm ci
npm run dev
```

Откройте адрес Vite (обычно http://localhost:5173). Нужен интернет для тайлов карт. В Windows PowerShell команды — `npm.cmd` и `npx.cmd`; отдельная установка браузеров Playwright не нужна, используется системный Edge.

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер разработки |
| `npm run build` | типы + сборка в `dist/`, относительные пути |
| `npm run preview` | просмотр сборки |
| `npm test` | юниты Vitest |
| `npm run check` | типы + все юниты |
| `npm run test:e2e` | сквозные проверки UI/экспорта в Edge (`RS_E2E_CHANNEL=chrome` — Chrome) |
| `npm run exports` | шесть новых MP4 в `exports/redesign/`, плеер и декодирование кадров |
| `node scripts/make-style-thumbs.mjs` | три статические миниатюры настоящего рендера |
| `node tests/e2e/acceptance-materials.mjs ui` | локальные скриншоты всех состояний UI и контактные листы |
| `node tests/e2e/acceptance-materials.mjs frames` | RU/EN, последовательные кадры и seek, сравнения с MP4 |
| `node tests/e2e/acceptance-materials.mjs data` | синтетика и локальные GPX из tracks/, замеры объёма |
| `node tests/e2e/acceptance-materials.mjs local` | локальное открытие уже снятых частных демо, сценарий меток |
| `npm run build:geodata`, `npm run build:sample` | разовая пересборка данных с сетью; для приёмки не требуется |

## Форматы и достоверность

**GPX**: trk/trkseg/trkpt и rte/rtept; время и высота необязательны. Именованные wpt рядом с треком дают события. **GeoJSON**: LineString/MultiLineString, Feature/FeatureCollection, координаты `[lon, lat, ele?]`, время в coordTimes/times. **CSV**: заголовок lat/lon (latitude/longitude, широта/долгота), необязательные ele/time; разделитель запятая или точка с запятой. Несколько файлов склеиваются по времени, без времени — в порядке выбора.

**Разрывы трека** показываются пунктиром. Итоги различают километры по записанному треку и разрывы; разрыв не доказывает способ передвижения. Эвристика зависит от шага записи, редкий логгер требует осторожной интерпретации. GPS-выбросы, дубликаты и некорректные координаты очищаются; пустой/нечитаемый файл даёт сообщение об ошибке.

**KML/KMZ**: линии и метки; линия имеет приоритет как трек. Метки без линии образуют историю по точкам: связи между ними не являются подтверждёнными дорогами. Километраж и скорость у такой истории не показываются. Время создания метки не доказывает дату прохождения. Город подписывается «рядом», только если он найден. Семантика цветов транспорта/ночёвок применяется только к известному экспорту Organic Maps, прочие цвета имеют неизвестный смысл.

**Главы**: JSON по [схеме](public/samples/chapters.schema.json) выбирается вместе с маршрутом. Показываются только главы с совпавшей привязкой к меткам; воспоминания помечены источником. Редактора глав и вставок фото/видео сейчас нет (T22 отложен). Частные примеры доступны только локально в dev; их исходники, кадры и ролики не входят в публичную сдачу.

Пример @wahrier — **реконструкция по афише, не GPS-запись**. Геометрия проложена по дорогам OSM, время и высоты расчётные; дата/день/скорость выключены по умолчанию, реконструкция помечена в кадре. Пример по меткам — отдельный локальный dev-сценарий, не замена реконструкции.

## Новые контрольные видео

Матрица снимается продуктом через UI: H.264 MP4, 30 кадров/с. Фактические результаты открытия плеером и декодирования — в [визуальном отчёте](docs/visual-review/report.md).

- [Экспедиция 9:16 RU](exports/redesign/expedition-9x16-ru.mp4), [16:9 EN](exports/redesign/expedition-16x9-en.mp4) — 30 с;
- [Атлас 9:16 EN](exports/redesign/atlas-9x16-en.mp4), [16:9 RU](exports/redesign/atlas-16x9-ru.mp4) — 30 с;
- [Неон 9:16 RU](exports/redesign/check/neon-9x16-ru.mp4), [16:9 EN](exports/redesign/check/neon-16x9-en.mp4) — 15 с.

Предыдущие `exports/route-story-wahrier-*.mp4` сохранены отдельно. Скрипт защищён от перезаписи новых файлов; `RS_EXPORT_ONLY` выбирает строку матрицы, `RS_EXPORT_REVIEW_EXISTING=1` повторно проверяет уже снятый новый MP4, не меняя его. Приёмка Instagram/Telegram не выполнялась. Тяжёлые кадры и частные MP4 сохраняются только в локальном scratchpad T15, компактные сравнения — в docs/visual-review/.

## Архитектура

Файл → route → geo → story → render → export. География Natural Earth встроена. Timeline считает историю и камеру от времени кадра; MapLibre рисует подложку и рельеф, Canvas 2D — маршрут, титры и показатели. Превью и экспорт используют одну сцену и общие timelineOptions. Экспорт кадр за кадром ждёт ресурсы и кодирует H.264 MP4 (WebM — запасной вариант по поддержке браузера). Слабое оборудование и сеть увеличивают время работы; фактические замеры — в отчёте. [Подробнее](docs/architecture.md).

Право публикации кадров Esri не заявляется. Атрибуция всегда входит в видео.

## Ограничения

- Проверенный экспорт — десктопный Edge. Chrome поддерживается механизмом WebCodecs, но отдельный прогон этой приёмки выполнен в Edge. Safari, реальные телефоны и приложения соцсетей не проверялись; мобильные размеры проверяются в десктопном браузере.
- Неполные тайлы дают предупреждение; такой файл не считается полным успешным результатом. Сворачивание вкладки замедляет экспорт.
- Звука, медиа-врезок и многодорожечного монтажа нет. Переключатели убирают показатели, однако титры, события, итог и атрибуция остаются; отдельный режим для своего монтажа не строился.
- Маршруты через 180° меридиан отклоняются. «Рядом» не доказывает посещение города; личные метки и главы — только локально.
