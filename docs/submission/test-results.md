## Финальная пара подачи

Снята через настоящий интерфейс в Edge: маршрут по меткам Organic Maps с явным подтверждением порядка, файл глав, стиль «Экспедиция», RU, 60 с. Каждый файл полностью декодирован `VideoDecoder` в Edge и открыт плеером.

| Файл | Кадр | Длительность | Кадров декодировано / пустых | Время экспорта |
|---|---|---|---|---|
| [route-story-9x16.mp4](../../exports/submission/route-story-9x16.mp4) | 1080×1920, H.264 30 к/с | 60,00 с | 1800 / 0 | 43 с |
| [route-story-16x9.mp4](../../exports/submission/route-story-16x9.mp4) | 1920×1080, H.264 30 к/с | 60,00 с | 1800 / 0 | 44 с |

Кадры 3/12/21/30/39/48/58 с: [9:16](frames-9x16.jpg), [16:9](frames-16x9.jpg). Ошибок экспорта и предупреждений о тайлах нет. Отдельно снят «обзор по меткам» 16:9 (точки без линий и без порядка) — 1800 / 0, в подачу не входит.

Содержание: Турция → Грузия → Армения → Иран → Казахстан → Узбекистан → Таджикистан → Узбекистан (7 стран, 214 меток, 158 мест ночёвки), главы «со слов путешественника», в кадре пометка «маршрут по меткам, не GPS-трек»; километража и скорости нет. Координаты в кадре — сетка 0,1° выборки, не точные места.

**Подготовка данных.** Время метки — момент создания закладки, а не дата визита ([ADR 0010](../adr/0010-waypoints-not-a-track.md)). В выборке было шесть одиночных меток в другой стране посреди чужого участка (закладки, созданные вне хода поездки); при порядке по времени закладок они давали ложные переезды. По решению владельца проекта они исключены из выборки для роликов (220 → 214 меток); исходные данные путешественника не изменялись.

## Проверка перед защитой

На обновлённом сайте пройти [сценарий](demo-script.md): загрузить маршрут → выбрать стиль → Play/replay → «Экспортировать ролик» → открыть скачанный MP4. Встроенный пример обозначен как реконструкция; у меток отсутствуют километры и скорость, порядок закладок требует явного подтверждения.
