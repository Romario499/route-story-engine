# Сценарий показа жюри (≤ 2 минуты)

**Адрес:** https://romario499.github.io/route-story-engine/ — десктопный Edge или Chrome (экспорт MP4 требует WebCodecs H.264). Ничего устанавливать не нужно; файлы маршрута не покидают браузер.

| Время | Действие | Что видно |
|---|---|---|
| 0:00–0:15 | Открыть адрес. | «Студия путешествий»: шаги «Маршрут → Стиль → Сцены → Экспорт», превью, панель стиля. |
| 0:15–0:35 | Нажать **«Пример: маршрут @wahrier»** (или «Заменить файл» → свой GPX/KML/KMZ/GeoJSON/CSV). | Сводка маршрута (км, точки, страны), превью строится автоматически; дорожка «Сцены» собирается сама — вступление, путь, страны, финал. |
| 0:35–0:55 | Стиль **«Экспедиция»** → формат **9:16** или **16:9** → длительность **30 с**. | Спутник и рельеф DEM, светящаяся линия маршрута, флаг и название страны, выноски «Рядом: город», показатели пути. |
| 0:55–1:20 | **Play** и перемотка по шкале. | Камера: обзор → подлёт → сопровождение головы маршрута → возврат к общему плану; в кадре честная пометка «DEM · вертикальный масштаб ×E». |
| 1:20–1:50 | **«Экспортировать ролик»**. | Прогресс по кадрам; готовый MP4 (1080×1920 или 1920×1080, 30 к/с) скачивается автоматически. Экспорт 30-секундного ролика на проверенной машине — 30–60 с. |
| 1:50–2:00 | Открыть скачанный MP4. | Тот же кадр, что в превью: превью и экспорт используют один рендер. |

Готовые ролики, если показ идёт без сети: `exports/submission/route-story-16x9.mp4`, `exports/submission/route-story-9x16.mp4` (горный GPS-трек, см. `submission.md`).

Не сворачивать вкладку во время экспорта — браузер замедляет фоновые вкладки.
