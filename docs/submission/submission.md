# Route Story Engine — конкурс «Вайбатон · Route Story»

**Live URL:** https://romario499.github.io/route-story-engine/
**Репозиторий и README:** https://github.com/Romario499/route-story-engine

## Что это

Браузерное приложение превращает GPS-трек или метки путешествия в видеоисторию: **ROUTE → STYLE → REPLAY → EXPORT**. Импорт — GPX, KML/KMZ, включая Organic Maps, GeoJSON, CSV и файл глав JSON по [схеме](../../public/samples/chapters.schema.json). Экспорт — H.264 MP4 через WebCodecs в Chrome/Edge, WebM как запасной вариант. Без бэкенда, аккаунтов и ключей; маршрут обрабатывается локально в браузере.

## Как работает история

1. **ROUTE:** импорт маршрута; для Organic Maps — выбор участка и явное подтверждение порядка закладок. Метки не выдаются за GPS-трек: без километража и скорости. Разрывы настоящего трека не соединяются.
2. **STYLE:** «Экспедиция» — спутник EOxCloudless 2016 (CC BY 4.0), DEM AWS Terrain и OpenFreeMap; «Атлас» — светлая карта OSM с отмывкой; «Неон» — тёмная карта. Форматы 9:16/16:9, длительности 15/30/45/60 с, RU/EN.
3. **REPLAY:** камера шести сцен ведёт историю от общего плана к движению и итогу. В финальной паре история начинается раньше; плашки всех 7 стран держатся ≥ 90 кадров каждая, выноски глав — 3–5,5 с в обоих форматах, в 16:9 есть крупные планы глав. Раскладка без перекрытий; показатели — по доступным данным. Вертикальный масштаб DEM подписан; реконструкция помечена.
4. **EXPORT:** общий рендер для превью и видео, покадровая сборка файла в браузере. На защите после экспорта открываем скачанный MP4.

Кнопка «Пример: маршрут @wahrier» на сайте загружает помеченную реконструкцию. Реальные метки конкурсных роликов не встроены в публичный пример.
