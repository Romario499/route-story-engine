# ADR 0010: метки путешествия не являются GPS-треком

Дата: 2026-10-11. Статус: принято для таска 18 (G69–G72, G76).

## Решение

KML читается ограниченным XML-сканером без DOM, DTD и внешних сущностей. KMZ читается
по центральному каталогу ZIP: stored/deflate, CRC32, ограничения размеров и числа файлов.
В браузере deflate распаковывает `DecompressionStream('deflate-raw')`; офлайн-скрипт и
Node-тесты используют встроенный `zlib`. Зависимости не добавлены. Все вложенные KML
читаются ровно один раз; NetworkLink разрешён только внутри KMZ, только на имеющийся
KML без выхода из архива; относительный `..` внутри архива допустим. Внешние ссылки и небезопасные пути отклоняются без сети.
Служебный индекс KML со ссылками учитывается отдельно от коллекций, пустые коллекции сохраняются в отчёте.

`JourneyWaypoint.markedAt` — epoch ms создания закладки, **не дата визита**. Высота
Point и время закладки не копируются в GPS-поля `ele`/`time`. Технические дубли
сводятся по имени, координатам до 1e-6 и markedAt. `duplicates` — число дополнительных
копий; источник первой копии сохраняется, статистика всех коллекций остаётся в отчёте.
Конфликт типов у дублей даёт unknown, а не подтверждённый тип.

Единственная таблица семантики — `WAYPOINT_COLOR_SEMANTICS` в `src/route/waypoints.ts`.
Основание: последнее Дополнение `2026-10-11-brief.md`, объяснение Шаха о данных @wahrier:
green/lime → overnight/stated, yellow → train/stated; red → stop/unknown.
`stated` подтверждает объяснение цвета, но не отдельную ночёвку, дорогу или дату визита.
Другие цвета дают unknown. Эта семантика не универсальна для произвольных экспортов.
Таблица применяется только при распознанном Organic Maps (`organic`); остальные KML
получают unknown/unknown независимо от цвета значка. Hex-цвет сохраняется как исходная
строка, без догадок о соответствии green/lime и типе события.

Для Organic Maps (ссылки на стили placemark-*) отбор путешествия: первая lime/green
в географической рамке Турции (26–45°E, 35–43°N) не раньше ноября 2024 года,
до последней метки; цвета lime/green/yellow/red. Это эвристика отбора, не проверка
государственной границы. Если начальная метка не найдена — нижняя граница 2024-11-01.
`summarizeKmlImport(tracks, {from, to})` позволяет явно задать период. Без времени либо
вне отбора — личные, исключены из Route; отчёт считает исключённые уникальные метки.
Для обычных Google Earth Point без соглашения Organic Maps сохраняются неизвестные
события, в том числе без времени. Их тип нельзя считать подтверждением путешествия.

Если в KML/KMZ есть LineString или gx:Track с ≥2 точками, Route строится из сегментов
как GPS-трек; Point используются как подписи на нём. Режим меток включается только
при отсутствии таких сегментов, в том числе для смешанных бэкапов Organic Maps.
Route из меток получает `source.kind = 'waypoints'`, `journeyWaypoints` и `importReport`.
`totalM`/`ownM`/накопленные `d` равны нулю, hasTime/hasEle false; скорость, GPS-дни,
даты визитов и набор высоты отсутствуют. Эти нули означают отсутствие GPS-метрики.
Таск оформления должен учитывать source.kind и не показывать их как километраж.
Совместный импорт GPX и меток отклоняется: их нельзя молча слить в подтверждённый трек.
Прежний GPX/GeoJSON/CSV-конвейер сохраняется.

## Приватность и офлайн-выборка

Исходный KMZ и точные метки живут только локально; синтетические фикстуры не содержат
координат путешественника. `scripts/waypoints-sample.mjs --report` ничего не пишет:
печатает структуру, агрегаты и SHA256, без координат/имён точек. Сводки со списком
коллекций предназначены для локальной проверки, не для публикации.

`--segment YYYY-MM-DD YYYY-MM-DD` выбирает включительно календарные UTC-даты;
`--out` по умолчанию — `private/waypoints-<from>-<to>.json`. Координаты округляются до
сетки 0.1°, последние 90 календарных дней относительно даты файла исключаются.
Названия Point не включаются в выборку; `source.file` и `source.collection` содержат
только имя коллекции без пути, а не локальный путь или имя вложенного KML.
Дата берётся из суффикса `_YYMMDD.kmz`; при неизвестной дате обязателен `--file-date`.
Граница ровно 90 дней сохраняется; будущие и недатированные метки не публикуются.
Запись `wx` запрещает перезапись любых существующих файлов и алиасов исходника.
SHA256 исходника проверяется повторно после работы. Скрипт не копирует сырой архив.

Выбор участка и огрубление не являются разрешением на публикацию. Ничего не
записывается в public автоматически; размещение выборки и роликов требует отдельного
разрешения путешественника. Прежний демонстрационный GPX не заменяется.

## Проверка настоящего бэкапа

Локальный `--report`: 26 коллекций плюс служебный индекс, 10 615 точек, 870 уникальных,
9 745 технических дублей, 2 линии. По правилам отбора — 529 меток путешествия и
341 исключённая личная. Дополнительные агрегаты вводной не воспроизвелись буквально:
при явной границе 2025-05-01 зелёная цепочка содержит 338 точек (медиана 23 км,
90-й процентиль 291 км, максимум 6 306 км); во всём периоде начиная с первой
отобранной метки — 93 соседних пары <2 минут из 541. Не следует подгонять отбор
под предварительный анализ или принимать расстояния по прямой за километры трека.
